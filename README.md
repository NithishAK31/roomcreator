# RoomCreator

RoomCreator is a web application that converts natural language room requirements into editable 2D blueprint layouts.

## Features

- Natural language room description
- Rule-based requirement extraction
- Automatic room placement
- Interactive blueprint editor
- Drag and resize rooms
- Save layouts
- Responsive interface

## Tech Stack

Frontend
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

Backend
- Supabase

Algorithms
- Regex-based Natural Language Parsing
- Rule-based Layout Generation
